# SaSx — техники и чакра для Left 4 Dead 2

Первый прототип, версия **0.1.0**: серверный плагин SourceMod для проверки
чакры и мощного огненного шара. Он использует частицы огня и взрыва из L4D2;
сторонние модели, аниме-эффекты, новые текстуры и графические улучшения не нужны.

## Что уже реализовано

- Каждому выжившему на старте карты/раунда даётся 100 чакры.
- Огненный шар стоит 25 чакры; полного запаса хватает на четыре применения.
- Подготовка занимает 0,85 секунды, затем снаряд летит в направлении взгляда.
- Во время подготовки блокируются стрельба, толчок, перезарядка и использование.
- Регенерация: 1 чакра/секунду, начиная через 5 секунд после начала техники.
  Подготовка и обездвиживание приостанавливают восстановление.
- Полёт проверяется объёмной трассировкой; снаряд взрывается при столкновении
  или после 1800 игровых единиц. Скорость — 1100 единиц/секунду.
- Радиус взрыва — 500 единиц. Урон — 300 в центре и 105 на границе.
  Стены и твёрдые препятствия блокируют поражение; заражённые не экранируют толпу.
- Танк получает 25% рассчитанного урона. Прямого урона выжившим нет.
- Подготовка отменяется при смерти, падении, захвате особым заражённым,
  смене команды и завершении раунда. Зарезервированная чакра возвращается;
  уже выпущенный шар при этих событиях удаляется без возврата стоимости.
- Чакра и перезарядка передаются между игроком и его ботом при переходе в AFK.
  Боты получают запас чакры, но самостоятельно техники пока не применяют.
- Параметры доступны через конфигурацию без перекомпиляции плагина.

Это **первая проверка механики**, не законченный мод. Пока отсутствуют ручные
печати и новые анимации, случайные три техники, замена оружейных ячеек, кунай,
солдатские пилюли и их размещение на карте. Оружие, аптечки и обычные таблетки
сохранены для сравнительного теста. Прототип не создаёт длительные очаги огня:
урон наносится один раз при взрыве. Переподключение сейчас создаёт новый запас
чакры; сохранение за персонажем между переподключениями — задача полного мода.

## Установка готовой сборки на Windows

Готовый архив: [скачать через GitHub](https://github.com/lupaaemethdenia-bot/SaSx/raw/refs/heads/chakra-prototype/releases/0.1.0/l4d2-chakra-prototype.zip).
Если прямая ссылка не открывается, перейти к файлу
`releases/0.1.0/l4d2-chakra-prototype.zip` в ветке `chakra-prototype` и нажать
**Download raw file**. Для закрытого репозитория нужно войти в GitHub под
учётной записью с доступом к нему.

1. Установить совместимые с текущим сервером L4D2 версии MetaMod:Source и
   **SourceMod 1.12 или новее**, включая штатные расширения SDKTools и SDKHooks.
   Само скачивание архивов не устанавливает их. Инструкции:
   [MetaMod](https://wiki.alliedmods.net/Installing_Metamod:Source),
   [SourceMod](https://wiki.alliedmods.net/Installing_SourceMod).
2. Открыть корневую папку установленной игры или выделенного сервера,
   затем каталог `left4dead2` (в нём находятся `addons` и `cfg`).
3. Распаковать **содержимое** `dist/l4d2-chakra-prototype.zip` в этот каталог.
   Плагин должен оказаться в `left4dead2/addons/sourcemod/plugins/l4d2_chakra.smx`,
   конфигурация — в `left4dead2/cfg/sourcemod/l4d2_chakra.cfg`.
   Не заменять свою конфигурацию вслепую, если она уже существует.
4. Для локальной проверки добавить игре параметр запуска `-insecure -console`.
   Он нужен локальному серверу с плагинами. Для возвращения к обычной игре
   на защищённых серверах удалить `-insecure` и перезапустить игру.
5. Запустить локальную карту через консоль: `map c1m1_hotel coop`.
   Официальные серверы Valve этот серверный плагин не запускают.
6. В консоли проверить `meta list`, `sm plugins list` и `sm exts list`.
   `L4D2 Chakra: Fireball Prototype` должен быть загружен без ошибок,
   SDKTools и SDKHooks — работать.
7. Назначить свободную кнопку: `bind "v" "say !jutsu"`.
   Кнопка отправляет тот же запрос, что и работающая команда `!jutsu` в чате.
   Если V уже занята, использовать другую кнопку. `sm_chakra` показывает
   запас и перезарядку; в чате также доступны `!jutsu` и `!chakra`.
   Если клавиша не вызывает технику, выполнить `bind v` в игровой консоли
   и проверить, что привязка содержит `say !jutsu`. Чат-команда позволяет
   отдельно проверить запуск техники без привязки клавиши.

На выделенном сервере плагин и cfg устанавливаются **на сервер**. Клиентам
для этой версии дополнительные файлы не нужны: используются ресурсы игры.
Файл `.smx` подходит и для Windows, и для Linux.

## Первый игровой тест

Проверить [сценарии в docs/TESTING.md](docs/TESTING.md). Сборка и проверки
расчётов не заменяют запуск L4D2: визуальные эффекты, игровые сетевые свойства,
трассировки, урон и загрузка серверных расширений требуют проверки в игре.

Если плагин не запускается, нужны вывод `sm plugins list`, `sm exts list`
и записи из `left4dead2/addons/sourcemod/logs/errors_*.log`.
Если работает, но огонь не виден, отметить отдельно: штатные частицы
`fire_small_01` и `molotov_explosion` ещё требуют проверки на установленной игре.

## Настройки

Редактировать `cfg/sourcemod/l4d2_chakra.cfg` и выполнить в серверной консоли
`exec sourcemod/l4d2_chakra.cfg`, либо сменить карту. Изменение максимума
ограничивает текущий запас, но не выдаёт бесплатную чакру.

| Переменная | По умолчанию | Назначение |
|---|---:|---|
| `sm_chakra_enabled` | 1 | Включить/выключить прототип |
| `sm_chakra_max` | 100 | Максимальная чакра |
| `sm_chakra_fireball_cost` | 25 | Стоимость шара |
| `sm_chakra_regen` | 1 | Восстановление в секунду |
| `sm_chakra_regen_delay` | 5 | Пауза перед восстановлением |
| `sm_chakra_cast_time` | 0.85 | Подготовка в секундах |
| `sm_chakra_cooldown` | 2.5 | Пауза после выпуска |
| `sm_chakra_fireball_speed` | 1100 | Скорость полёта |
| `sm_chakra_fireball_range` | 1800 | Дальность полёта |
| `sm_chakra_fireball_radius` | 500 | Радиус поражения |
| `sm_chakra_fireball_damage` | 300 | Урон в центре |
| `sm_chakra_tank_scale` | 0.25 | Множитель урона по танку |

Это стартовые значения для тестирования, а не утверждённый баланс.

## Сборка из исходников

С Python 3.9+ и распакованным SourceMod:

```powershell
python tools/build.py --sourcemod "C:\path\to\left4dead2\addons\sourcemod"
```

Компилятор и includes берутся из указанного SourceMod. Для SDK из Git:

```bash
python3 tools/build.py --sourcemod /path/to/sourcemod --compiler /path/to/spcomp
```

На Linux можно воспроизвести проверенную облачную сборку через
`bash tools/bootstrap-linux.sh`. Понадобятся Git, GCC/G++, Python с venv и
доступ к GitHub/PyPI. Скрипт использует зафиксированные версии официальных
исходников, не меняет установку системного Python и не запускает игру.

Результат: `dist/l4d2_chakra.smx` и `dist/l4d2-chakra-prototype.zip`.
