# Chakra prototype 0.1.0

First gameplay prototype: chakra, regeneration and a castable fireball. The ZIP contains the compiled plugin, configuration, source code and installation instructions.

Download [l4d2-chakra-prototype.zip](https://github.com/lupaaemethdenia-bot/SaSx/raw/refs/heads/chakra-prototype/releases/0.1.0/l4d2-chakra-prototype.zip), or open its GitHub file page and use **Download raw file**. Follow the root README to install it.

Compilation and 30 gameplay-math assertions passed. Actual L4D2 gameplay, particles and networking still require testing on a game server.
